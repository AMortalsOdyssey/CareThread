- 方法：对首页、录入来源、核对、记录库、详情、时间线、管理、老人今天、老人拍照和老人记录十处抽样，结合截图反查 `CTSpace.swift`。
- 4pt 网格抽样：`s1=4`、`s2=8`、`s3=12`、`s4=16`、`s5=20`、`s6=24`、`s7=28`、`s8=40`、`elderScreen=20`、`elderCard=20`。
- 触达尺寸复核：标准主按钮 50pt；老人主按钮 60pt、列表行 64pt、触达区 56pt、资料类型选项 88pt。
