- [x] `Q02` 对比适合 iOS/App Store 的许可证与分发约束；保持一期 GPL/AGPL 依赖出局，并评估 MPL-2.0、Apache-2.0、MIT、双许可证和 source-available 的真实利弊。
- [x] `Q03` 分析抄袭、套壳、商标混淆、素材盗用、隐私冒用和恶意二进制风险；给出商标、软件著作权、品牌/素材保留、签名发布和侵权取证的分层措施。
- [x] `Q04` 把“非盈利倾向、维护资源有限、希望社区提升信任和 Android 扩展、又保留未来商业化”作为同一组约束，不假设长期全职团队。
- [x] `Q05` 调研同类本地/离线病历、家庭健康档案和隐私优先 App 的开源状态、功能、定价、维护和用户反馈；产品自述与独立用户证据分开。
- [x] `Q06` 比较完全免费、付费下载买断、免费核心+一次性非消耗型内购、版本升级收费、订阅和未来 AI 单独付费；核算 App Store 费用/佣金、退款、家庭共享、服务器成本和用户信任。
- [x] `Q07` 未来 AI 必须作为新的联网/隐私/医疗合规决策，不默认复用一期“纯本地、未收集数据”结论；区分本地 AI、用户自带服务和开发者托管三种成本/风险。
- [x] `Q08` 输出 `docs/OPEN_SOURCE_AND_SUSTAINABILITY_STRATEGY.md`：唯一推荐路线、许可边界、仓库拆分、定价、12/24/36 月路线、触发切换条件和不可做事项，不留下开放决策给用户。
- [x] `Q09` 按用户当前决定在仓库加入标准 MIT License；README 明示商用/分发权限与保留版权声明义务，不把 MIT 误述为防套壳许可证。
- [ ] `Q10` 主开发最终验收后逐条回看 A–Q，确认本会话所有补充要求均有实现、测试、报告、真机待验或明确拒绝证据。
- [x] `Q11` 把“MIT 开源发布 → 自主推广与品牌积累 → 达到知名度后出售项目/业务资产”作为退出路线评估；覆盖可售资产、估值指标、App 转移、商标/域名、贡献者 IP 链、CLA/DCO、隐私数据不可随意交易和买方尽调。
