# CareThread 真实照片 OCR 基线

> 执行日期：2026-07-31
> 结论状态：可运行性、性能与单人一次字段判定已测；CER 与手写字段准确率不可计算
> 唯一产品决定：继续使用 Apple Vision，不切换 OCR 引擎

## 1. 结论

本轮 40 张真实照片已在本机、离线完成 Apple Vision 全量运行：40/40 页处理
成功，40/40 页产生非空文字结果，三次重复共 120 次推理的 P95 为 551 ms。
同一匿名集在 iPhone 17 Pro / iOS 26.5 模拟器单轮也是 40/40 成功、P95
1,664 ms，低于任务书 2 秒档位。现有 `ExtractionEngine` 在 35/40 页至少
产出一种结构化候选。

这些结果证明“真实图片可被当前本地链路处理”。在运行完成后，一名复核者对
40 页逐页目视分类，并对页面实际存在的日期、医院、类型、关键指标做了一次
人工判定：40 页均为打印为主，打印件字段合计命中 100/133（75.19%）。当前
样本没有以手写内容为主的页面，因此不能计算手写字段准确率。输入也没有逐字
双录参考文本，所以打印和手写 CER 仍不可计算；非空率、置信度和字段产出率
仍不作为准确率。

按 OCR 任务书 §5 的固定规则，换引擎必须同时满足：

1. 挑战者手写 CER 相对 Vision 改善至少 10 个百分点；
2. 挑战者打印 CER 相对 Vision 最多恶化 1 个百分点。

真实集缺少这两项所需真值，不能形成新的换引擎证据。已有可复现合成基准中，
RapidOCR 的手写 CER 只比 Vision 改善 1.56 个百分点，未达到 10 个百分点；
所以本轮唯一可执行结论仍是**维持 Apple Vision 单引擎**。

隐私措施：

- 含 OCR 原文及提取值的中间 JSON 只存在于权限 `0600` 的 `/tmp` 临时目录，
  聚合完成后删除。
- 人工判定只使用匿名编号与命中/未命中/不适用三态；逐页判定完成聚合后删除，
  不进入仓库。

  OCR 原文或字段值；敏感词与路径扫描零命中。
- 推理全程本机离线；没有上传、遥测或运行时模型下载。

## 3. 运行协议

- 引擎：发布基线 `Apple Vision / VNRecognizeTextRequest`。
- 配置：`.accurate`、`zh-Hans + en-US`、语言纠错、最小文字高度 `0.008`。
- 图像：Mac 基准读取方向元数据后归一化，最长边限制为 4096 px，避免把相机
  原图峰值直接等同于 OCR 模型峰值；模拟器轮直接使用 UIKit 解码并调用发布版
  `VisionOCREngine`，没有另改识别规则。
- 预热：第一张可处理图片预热一次。
- 计时：每页 3 次，共 120 次；报告中位数和 P95。
- 环境：Apple Silicon Mac、macOS 26.5、Xcode 26.6；这是本机 M 系基线，
  另在 iPhone 17 Pro / iOS 26.5 模拟器补跑单轮；两者都不是 iPhone 真机
  绝对性能。
- 提取：OCR 输出进入仓库当前 `ExtractionEngine`，不修改规则迁就样本。

### 运行时权限诊断

受限执行沙箱内，真实集 40/40 与合成集 31/31 都出现同一类 Foundation
Vision `nilError`；这排除了“真实照片损坏”这一解释。沙箱外的受控本机离线
诊断中，显式 request revision、`.accurate/.fast`、中英文语言组合、CPU-only
与 URL/CGImage handler 共 7 种策略，对一张合成图和一张匿名真实图均成功。
因此失败归因于执行沙箱无法访问 Vision 运行时服务，而不是样本或产品代码。
产品默认没有改为 CPU-only，也没有因诊断改变识别配置。

## 5. 单人一次字段级人工判定

| 字段 | 打印件命中/可判定 | 打印件准确率 | 手写件命中/可判定 | 手写件准确率 |
| --- | ---: | ---: | ---: | ---: |
| 日期 | 30/34 | 88.24% | 0/0 | 不可计算 |
| 医院 | 25/32 | 78.13% | 0/0 | 不可计算 |
| 类型 | 36/40 | 90.00% | 0/0 | 不可计算 |
| 关键指标 | 9/27 | 33.33% | 0/0 | 不可计算 |
| **合计** | **100/133** | **75.19%** | **0/0** | **不可计算** |

判定口径：逐页目视确认文档主要内容属于打印或手写；仅签名、勾画或少量批注
为手写，不把打印为主的页面改归手写。只把页面上明确存在且可辨认的字段放入
分母；缺页眉的续页、页面未展示的字段和无法可靠辨认的字段记为不适用。日期
允许命中页面上明确标注的一个有效业务日期；关键指标从化验/检查数值或用药
剂量中选取页面上明确可见的一项进行核对。类型使用 App 现有枚举，不支持的
单据统一按 `other` 判定。

这是**单人、一次、非双盲**判定：复核者在同一面板中能看到页面和 Vision 的
结构化输出，因此可能存在观察者偏差，不等同于两名标注者独立复核的正式真值。
不过命中必须与页面可见事实相符，不能仅凭“有输出”计为正确。当前 40 页均为
打印为主，故手写件分母为 0；这不是 0% 准确率，而是本批数据无法评价手写。

CER 仍至少需要逐字人工校对文本，最好由两次独立录入逐字符核对。用 Vision
输出自建参考会使 Vision CER 人为变成 0；用两个 OCR 结果的共识当真值也无法
判断两者共同犯错，所以本轮没有计算 CER。

## 6. 与合成基准对照

| 引擎/数据 | 打印 CER | 手写 CER | 字段命中 | M 系 P95 | 模拟器 P95 |
| --- | ---: | ---: | ---: | ---: | ---: |
| Vision 合成 P/H/D | 5.98% | 3.92% | 113/120（94.17%） | 229 ms | 695 ms |
| RapidOCR 合成 P/H/D | 2.34% | 2.37% | 105/120（87.50%） | 640 ms | 未集成 |
| Vision 真实照片（本轮） | 不可计算 | 不可计算 | 100/133（75.19%）打印件人工判定 | 551 ms | 1,664 ms |

真实照片 P95 比合成基准更高，符合照片分辨率、版面和图像解码更复杂的预期；
这是性能观察，不是准确率推断。合成集表明 RapidOCR 的字符错误率较低，但手写
改善仅 1.56 个百分点且字段命中更低，仍未通过固定换引擎门槛。

## 7. 可复现匿名标注协议

本轮已按匿名字段子集完成单人一次判定。后续若要计算 CER 或比较挑战者，仍需
建立独立人工真值；参考文本仅保存在本机 `/tmp` 或被 Git 忽略的私有目录，
不进入仓库：

```json
{
  "schema_version": 2,
  "samples": [
    {
      "id": "r001",
      "group": "R",
      "subgroup": "real",
      "document_style": "print",
      "image": "images/r001.jpg",
      "reference": "references/r001.txt",
      "scored": true,
      "expected": {
        "date": "2099-01-01",
        "type": "lab"
      }
    }
  ]
}
```

- `document_style` 只能是 `print` 或 `handwriting`；引擎切换基准必须两类至少
  各一页。本轮没有手写为主的页面，不能进入真实集换引擎评分。
- 参考文本由两次独立录入后逐字符核对；不能复制任一 OCR 引擎的输出充当真值。
- 日期、医院、类型、关键指标只标注页面实际存在的项；续页无页眉时不增加
  不存在的分母。
- 所有引擎读取同一图片、同一参考文本并进入同一 `ExtractionEngine`。
- 报告打印/手写 CER 与字段命中率分列，再执行“手写改善 ≥10pp 且打印恶化
  ≤1pp”的两条硬门槛；字段提升不能替代任一硬门槛。

## 8. 工具修正与验证

本轮修正 `score_real.py` 及真实集说明：

- 删除自创的“CER 相对改善 50% + 字段提升 5pp”换引擎条件；
- 强制真实清单包含 `document_style`，并要求打印/手写两组均有样本；
- CER、字段命中和 P95 按打印/手写分组汇总；
- 恢复任务书 §5 的 10pp/1pp 固定门槛；
- 用极小数值容差保护精确 10pp/1pp 边界，并校验每页字段分母与清单一致；
- 保留脱敏断言，输出不含参考文本、OCR 原文、字段值或本机路径。

验证结果：`python3 -m unittest Benchmarks/OCRBench/test_score_real.py`，11/11
通过；覆盖精确边界、单边失败、字段提升不可替代 CER 门槛、隐私输出、可选
字段的零/变分母、跨引擎分母与清单不一致时拒绝评分，以及缺少任一文档类别
时拒绝评分；重复页 ID 与重复引擎标识也会被拒绝，避免聚合静默覆盖。
